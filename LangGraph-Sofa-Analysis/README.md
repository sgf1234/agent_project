# LangGraph 沙发销售数据分析Agent
> 企业主流框架LangGraph实现的代码执行型复杂任务Agent，面向沙发家居公司业务数据分析
## 项目亮点
1. **显式State状态管理**：把问题、代码、报错、重试次数、结果全部放进状态，节点解耦
2. **多节点编排**：代码生成 → 安全沙箱执行 → 反思总结，分支路由自动重试
3. **Checkpoint持久化**：MemorySaver实现会话断点，任务中途停止后，同一个thread_id可以恢复执行
4. **安全管控**：代码黑名单过滤高危语句，禁止网络、文件读写、系统调用
5. **自动反思重试**：代码报错时自动交给LLM自查、修正代码，最多2次重试，防止死循环
6. 业务落地场景：家居沙发公司销售数据分析，自然语言查询销量、利润、渠道分布，不用写SQL/Python

##  技术栈
LangGraph, DeepSeek LLM, Pandas, LangChain, Pydantic

## 业务数据说明
内置沙发销售数据集：材质（布艺/真皮/科技布/猫抓布）、售价、成本、销售渠道、年月、地区、销量，支持利润计算：利润=(售价-成本)*销量

## 启动
1. 配置.env：DEEPSEEK_API_KEY=sk-xxx
2. pip install -r requirements.txt
3. python main.py

##  测试提问示例
- 2026年布艺沙发总销量是多少？
- 哪个渠道真皮沙发的总利润最高？
- 浙江地区所有沙发的总销售额？

## 局限 & 优化方向
1. 当前是内存MemorySaver，生产替换为Redis/SQLite持久化
2. 沙箱是简易版，生产要使用隔离沙箱（如E2B）
3. 可以增加意图分类节点，区分数据分析、咨询类问题
4. 可以增加人工审核节点，复杂计算需要人工确认后再执行
